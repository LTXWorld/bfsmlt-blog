# My Blog Project

## Goal
Build a minimal static blog site similar to mariozechner.at.

## The Stack
- Static site generator: use plain Node.js scripts, no heavy frameworks
- Markdown files for posts (stored in /posts/)
- Mustache or simple string templates for HTML generation
- Pure CSS with no external dependencies
- Output to /dist/ directory

## Structure
- /posts/YYYY-MM-DD-slug/index.md (blog posts)
- /src/template.html (HTML template)
- /src/styles.css (styles)
- /build.js (static site generator script)
- /dist/ (generated output)

## Style Reference
- Minimal, text-focused design
- Serif font for headings (like Georgia or similar)
- Grid/graph paper background texture
- No tracking, no cookies, no JS frameworks
